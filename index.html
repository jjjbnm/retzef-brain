איך מתחברים ל־Retzef API?

שלח בקשת POST עם Authorization Bearer והודעות בפורמט chat completions.

const response = await fetch(
  "https://retzef-brain.vercel.app/api/v1/chat",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer YOUR_API_KEY"
    },
    body: JSON.stringify({
      model: "retzef-code",
      messages: [
        { role: "user", content: "Hello Retzef!" }
      ]
    })
  }
);

const data = await response.json();
console.log(data.choices[0].message.content);
⚠️ מפתחות API הם סודות. השתמש בהם בשרת שלך בלבד, לא בקוד JavaScript שרץ בדפדפן של מבקרים.
